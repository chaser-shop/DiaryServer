# Back-office: каталог, ціни, замовлення (MongoDB)

Закрита адмін-система. **Публічного сайту й Telegram-бота тут немає** (обрано варіант «А»).
Усі маршрути, крім `/health` і входу, вимагають авторизації.

## Юридичні обмеження (закон № 1978-IX, чинний з 11.07.2023; не юридична консультація)
- Реклама e-сигарет і рідин заборонена, зокрема в інтернеті; публічний каталог із цінами/фото ризикований.
- Заборонені рідини з ароматизаторами, у контейнерах понад 10 мл або з нікотином понад 20 мг/мл.
- Тому всі 589 рідин імпортуються зі статусом `blocked_by_law`: їх не можна додати в замовлення, і це не вимикається налаштуванням.
- Под-системи, картриджі, підсилювачі: `hold_legal_review`. Картриджі з ємністю понад 2 мл додатково позначаються `tank_over_2ml_check`.
- Перш ніж будувати публічну частину, проконсультуйтесь із юристом.

## Запуск
1. Python 3.12: `python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt`
2. MongoDB: або `docker compose up -d` (локально), або рядок підключення MongoDB Atlas (Database → Connect → Drivers) у `MONGODB_URI`.
3. `cp .env.example .env`, заповніть `MONGODB_URI` і `JWT_SECRET` (мін. 32 символи).
4. Перший адмін: `python -m backend.cli create-admin` (пароль від 10 символів, зберігається як Argon2-хеш).
5. Імпорт прайсу: `python -m backend.cli import-products` (перегляд), потім `... --apply`. Повторний імпорт безпечний: дублікатів немає, оновлюються лише ціна й наявність, націнка не нашаровується.
6. Сервер: `uvicorn backend.main:app --host 127.0.0.1 --port 8000` → http://127.0.0.1:8000/admin/
7. Перевірка: `/health` повертає `{"ok": true}`, вхід працює, у «Товарах» 800 позицій.

## Правила
- Ціни: `final = purchase + markup(category)`; рахує лише backend. USDT-позиції: USDT × курс, округлення вгору до цілої грн. У списку ціна в грн, у картці товару ще й USDT.
- Націнки: рідини +10, под-системи +70, пачки картриджів +15, підсилювачі 0 (змінюються в розділі «Націнки» з попереднім переглядом).
- У замовленні ціна фіксується на момент створення; суму завжди рахує сервер.
- Захист: Argon2, JWT, блокування на 15 хв після 5 невдалих входів, журнал дій у `audit_log`.
- Фото з xlsx прив'язані до лінійки/моделі, а не до конкретного смаку чи кольору.

## Тести
`python -m pytest` (повний набір, потрібен `pip install -r requirements.txt`) або без залежностей `python -m tests.run_pure`.

## Не реалізовано (свідомо)
Публічний сайт, Telegram-бот, оплата, імпорт сирого Excel/CSV (імпортується `products_clean.json`). Колекції `users`, `carts`, `brands` не створюються, бо без бота й сайту вони не потрібні.
