# НАВС — Електронний щоденник

Vite + React (фронтенд) і Vercel Serverless Functions + MongoDB (авторизація).
Спочатку екран входу, після входу — головна панель.

## Змінні середовища (Vercel → Settings → Environment Variables)

| Змінна | Опис |
| --- | --- |
| `MONGODB_URI` | рядок підключення MongoDB Atlas |
| `MONGODB_DB` | назва бази (необовʼязково, за замовчуванням `navs-era`) |
| `JWT_SECRET` | довгий випадковий рядок (`openssl rand -base64 48`) |

У MongoDB Atlas: Network Access → дозволити `0.0.0.0/0` (Vercel не має фіксованого IP).

## Деплой
1. Завантажити проєкт у GitHub-репозиторій, імпортувати в Vercel (Framework: Vite).
2. Додати змінні середовища, натиснути Deploy.

## Панель адміністратора (`/admin`)
Увійдіть як `admin` і відкрийте `/admin` (або «Адмін-панель» у меню профілю).
Вкладка «Групи» → «Створити групу», вкладка «Студенти» → «Створити студента»: вказуєте ПІБ
і групу зі списку, система генерує логін і тимчасовий пароль та показує їх у вікні з кнопками
копіювання. Логін і пароль завжди видно адміністратору в картці студента.
Усе зберігається в MongoDB (колекції `groups`, `students`, `grades`, `lessons`, `activity`),
студенти входять на головну сторінку зі своїм логіном і паролем.

> Тимчасовий пароль зберігається в `students.tempPassword` відкритим текстом, щоб адміністратор
> завжди його бачив; для входу використовується окремий bcrypt-хеш.

## Параметри групи: сесія, розклад, посилання на пари
Адмін-панель → «Групи» → група → вкладка «Налаштування». Нижче «Параметрів групи» є три блоки:

- **Початок сесії** — дата; студенти бачать у блоці «До сесії» кількість днів до неї.
- **Розклад занять** — завантаження `.xls`/`.xlsx` з порталу розкладу (файл читається в браузері
  адміна, на сервер зберігаються лише розпізнані пари). Блок «Наступна пара» у студентів рахується
  від поточного часу (Europe/Kyiv) за цим розкладом; нове завантаження замінює попередній розклад.
- **Предмети та посилання на пари** — посилання (Zoom/Meet/Teams) для кожного предмета групи;
  відкривається кнопкою «Перейти до заняття».

Усе зберігається в документі групи (`groups.sessionStart`, `groups.schedule`, `groups.subjectLinks`).
Бібліотека читання Excel (`xlsx`) ставиться з cdn.sheetjs.com — після оновлення виконайте `npm i`.

## Службовий користувач
`admin` / `admin123` створюється автоматично при першому вході (колекція `users`).
Також: `npm run seed` (з `.env.local`). **Після першого запуску змініть пароль.**

## Локально
`npm i -g vercel && npm i && vercel dev` (потрібен `.env.local` за зразком `.env.example`).
Звичайний `npm run dev` показує лише фронтенд — `/api` працює тільки через `vercel dev` або на Vercel.
